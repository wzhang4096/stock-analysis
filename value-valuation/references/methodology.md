# 估值方法论（methodology）

> 本 Skill 的目标：用 **PE-TTM 历史分位** 为主轴，对个股 / 指数做"贵不贵、是不是价值陷阱"的客观估值诊断。
> 适用前提：标的为**盈利相对稳定、有连续 4 季以上归母净利**的公司或宽基指数。亏损股 / 强周期股见第五节特殊处理。

---

## 一、PE 口径：分母优先用"扣非归母净利"

| 口径 | 分母 | 用途 |
|---|---|---|
| **PE-TTM（主用）** | 最近 4 季 **扣非归母净利** 之和 | 估值主轴，剔除一次性损益 |
| 静态 PE（辅助） | 上一年度年报归母净利 | 检验盈利是否突变 |
| 动态 PE（谨慎） | 分析师一致预期全年净利 | 仅做保守情景假设，**禁用行情软件机械年化** |

**关键规则**：当"归母净利 TTM"与"扣非净利 TTM"差异 > 15% 时，**一律以扣非口径为准**，并在输出中明示一次性损益占比。

- 归母 >> 扣非（如腾讯，处置资产收益）→ 归母口径会**系统性低估 PE、高估便宜度**，必须用扣非；
- 归母 ≈ 扣非 → 两者皆可，以接口 PE 交叉验证（差异 > 10% 需排查口径）。

---

## 二、历史分位：多窗口 + 主用 10 年

### 窗口优先级
- **主用 10 年**：覆盖完整牛熊，含 2008/2015/2018/2021 等极值，最稳健；
- **5 年辅助**：赛道结构变化快（科技 / 新能源）时用 5 年交叉验证；
- **1 年 / 3 年**：仅看短期情绪，**不单独作为买卖依据**；
- **20 年**：仅做极值参照（行业权重变迁会导致失真）；
- **上市 / 数据不足 10 年**：用"上市以来全数据"，但必须标注样本局限。

### ⚠️ 窗口陷阱（必读）
同一个"80% 分位"在不同窗口下含义天差地别：拉长到 20 年可能只是 5 年窗口的 40%。
**要求**：输出时必须**同时列出 1y / 3y / 5y / 10y 分位**，若各窗口差异 > 20 个百分点，需解释（通常是历史极端值稀释了分位）。**严禁跨窗口混用阈值**。

---

## 三、估值判定：20 / 70 双阈值 + 细分带

| 分位区间 | 状态 | 操作倾向 |
|---|---|---|
| **< 20%** | 极度低估 | 安全边际高，分批建仓 |
| 20% – 50% | 低估 / 合理偏低 | 可定投 |
| 50% – 70% | 合理中枢 | 持有，赚业绩增长的钱 |
| 70% – 90% | 偏高 / 高估 | 停止买入，分批减仓 |
| **> 90%** | 极度高估 | 止盈 |

阈值来源：国内通用 30/70 与桥水 20/80 的折中。

---

## 四、三道关：防价值陷阱（**按盈利趋势分型**）

> **核心升级**：不再"一套规则通吃"。先判定标的的**盈利趋势分型**，再套差异化判据。

### 第一步：判定盈利趋势分型

| 类型 | 特征 | 典型 |
|---|---|---|
| **A. 稳定成长** | 净利增速 10%~40%，ROE 稳定 | 成熟消费、平台型科技（如腾讯） |
| **B. 高速成长** | 净利增速 > 40% 或 3 年复合 > 50% | 新能源、AI、困境反转初期 |
| **C. 周期型** | 盈利随行业景气大幅波动 | 煤、油、有色、航运、券商 |
| **D. 困境 / 负增长** | 净利增速 < 0，或连续下滑 | **盈利承压的传统龙头（如小米当前）** |

### 第二步：差异化三道关

#### 通用关（四型都要过）
- **关0 绝对值**：PE 分位低 **且** PE 绝对值不高（如 < 25 倍），才是真低估；分位低但绝对值 50 倍 = 盈利崩塌，属陷阱。

#### A 型 / B 型（成长股）
- **关① 增速**：净利增速 ≥ 10%（A）/ ≥ 30%（B）视为合格；PEG = PE ÷ 增速，< 1 为低估、> 2 偏贵；
- **关② TTM vs 静态**：TTM 归母 < 静态归母 → 盈利加速（利好）；反之 → 减速，需警惕；
- **关③ 质量**：ROE ≥ 15%（A）/ 高增速可容忍较低 ROE（B）；毛利率、经营现金流为正。

#### C 型（周期股）⭐ 禁用单纯 PE 分位
- PE 在景气顶端最低、谷底最高，**低 PE = 卖点而非买点**；
- **改用**：① 跨周期平均盈利（过去 7-10 年归母均值）算"正常化 PE"；② PB + ROE + EV/EBITDA；
- 判定锚点：**PB 分位 + 行业景气位置**（如大宗价格、产能利用率），而非 PE。

#### D 型（困境 / 负增长）⭐ 最严格
- **关① 增速（一票否决）**：净利增速 < 0 → **PEG 无意义且为负，不能仅凭低 PE 买入**；
- **必须额外验证"盈利拐点"**：连续 2 季净利环比改善、或下一份财报净利转正，方可解除否决；
- **关② 趋势（技术面）**：要求股价**站上 MA20 且 MA20 拐头向上**（或至少收复 MA60），否则为空头排列，"低估值接刀"风险高；
- **关③ 预期差**：参考机构一致预期——若 80% 以上看多且目标价有 50%+ 空间，属"低估值 + 强预期"博弈区，**仅适合轻仓左侧 + 定投摊薄，禁重仓**。

### 第三步：结论映射
- 三道关全过 → 确定性低估，可布局；
- D 型未过关①（负增长）→ **标注"博弈区 / 需等拐点"，降级为观察**；
- C 型仍用 PE → **直接判定"方法不适用，请改用 PB"**。

## 五、特殊处理

| 情形 | 替代框架 |
|---|---|
| 强周期（C 型） | 跨周期正常化盈利 + PB-ROE + 景气位置 |
| 亏损 / 微利 | PB-ROE，或 PS（SaaS / 生物科技）|
| 不分红成长股 | 不看股息率，看自由现金流与再投资回报 |
| 港股 / 中概 | 叠加流动性折价、地缘政治折价（低估值可能"低很久"）|

## 六、输出契约（强制结构）

每份报告必须包含以下章节（详见 `output-contracts.md`）：
1. **当前核心数据**（股价 / 市值 / PE / PB / 股息率 / 52周位置 / YTD）；
2. **口径说明**（归母 vs 扣非，一次性损益占比，接口 PE 交叉验证）；
3. **PE-TTM 历史分位表**（1y / 3y / 5y / 10y 四行，含窗口陷阱提示）；
4. **三道关诊断**（先判分型 A/B/C/D，再逐关判定）；
5. **基本面交叉验证**（ROE、增速、PB/ROE、技术面、机构评级 / 一致预期）；
6. **综合结论 + 操作倾向**；
7. **免责声明**。

> 数据口径：行情取自 `westock quote`，财务取自 `westock finance --type income`（归母净利滚动 4 季），技术面取自 `westock technical`，机构预期取自 `westock rating` / `consensus`。价格单位统一为"元/股"，市值与净利统一换算为"亿"后再相除，避免单位错乱导致 PE 偏差。
