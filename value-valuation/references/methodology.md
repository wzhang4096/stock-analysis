# 估值分位诊断 · 方法论（methodology）

## 1. PE 口径
- **主用 PE-TTM**（滚动4季归母净利 = 最新季 + 前3季）。
- 单日/单季净利不可直接套用历史价格序列（会失真），分母须用滚动4季净利。
- 静态 PE（上年同期净利）：仅用于校验，若 TTM 与静态差异大，说明近期净利突变，TTM 更可靠。
- 动态 PE（当年预测净利）：保守辅助，不单独作为结论依据。

## 2. 多窗口分位与阈值
| 窗口 | 用途 | 推荐度 |
|---|---|---|
| 1年 | 短期情绪、快速定位 | 辅助 |
| 3年 | 略长的情绪参考 | 辅助 |
| **5年** | 估值结构变化较大的赛道（消费/科技/AI） | 辅助 |
| **10年** | 宽基指数、老指数（覆盖完整牛熊）| **主轴** |
| 20年/上市以来 | 极值完整性（行业结构可能失真）| 验证 |

双阈值（20/70，国内通用30/70 + 桥水20/80，本 Skill 取 20/70）：
- <20% 低估 → 可建仓/定投，越跌越买
- 20%-50% 合理偏低
- 50%-70% 合理中枢
- 70%-90% 偏高
- >90% 极度高估 → 止盈清仓

## 3. 盈利趋势分型（决定三道关的执行口径）

> 为什么需要分型：**PE 分位低 ≠ 值得买**。同样是"分位 10%"，净利正增长（A 型）是真低估，净利崩塌（D 型）是价值陷阱——**不同盈利趋势下，同一套三道关的执行口径完全不同**。分型就是在跑分位之前，先给标的"定性"，避免"用一个规则套所有公司"。

### 3.1 四型总览

| 分型 | 中文 | 判定（满足即归入）| 分位参考 | 三道关松紧 |
|---|---|---|---|---|
| **A** | 稳定成长 | 净利同比>0、ROE 20%+ 或 3年复合高 | 偏低即低估 | **宽松**（常全过）|
| **B** | 高速成长 | 净利同比 50%+，增速未稳 | 偏低但需看持续性 | **关③最严**（看增速兑现）|
| **C** | 强周期 | 近12季净利 CV>0.5，单季大幅跳变 | **禁用单一PE** | 关①看周期位+拐点；用 PB/PS |
| **D** | 困境负增长 | 净利同比<0 且趋势向下 | 即便低分位也慎用 | **关①一票否决**（增速转正前不加仓）|

### 3.2 核心量化公式

```
净利同比(gr1y)   = (最新季归母净利 − 上年同期) / 上年同期
3年复合(CAGR3)   = (最新TTM净利 / 3年前TTM净利)^(1/3) − 1
ROE(年化)        = 归母净利(TTM) × 2 / (期初净资产 + 期末净资产)   # 近似年化加权
净利波动率(CV)   = 近12季归母净利标准差 / 近12季均值
                    ↑ CV > 0.5 是 C 型强周期的核心判据
环比斜率(slope)  = 近4季净利线性回归斜率（正=上行、负=下行）
```

**分型优先级**（互斥，自上而下命中即停）：
1. 若 `gr1y < 0` 且 `slope < 0` → **D 型**（困境负增长）
2. 否则若 `CV > 0.5` → **C 型**（强周期）
3. 否则若 `gr1y > 50%` 或 `CAGR3 > 40%` → **B 型**（高速成长）
4. 否则 → **A 型**（稳定成长）

### 3.3 各型详解

#### A 型 · 稳定成长（Stable Growth）
- **含义**：主业成熟、盈利可预测、长期双位数左右增长。
- **特征**：ROE 稳定在 15-25%、净利同比 +10%~+30%、CV < 0.5、季度间波动小。
- **三道关**：口径一致 + 净利正增长 + PEG<1 → 基本全过。**分位低即确定性低估**。
- **操作**：可作为核心底仓，分位<20% 可分批/定投。
- **案例**：腾讯控股（HK00700）——归母净利同比 +15.8%、ROE 10.2%(H1)/年化约20%、净利波动平稳 → **A 型稳定成长**。

#### B 型 · 高速成长（High Growth）
- **含义**：处于爆发期、净利增速极快但尚未稳定，估值对增速高度敏感。
- **特征**：净利同比 50%+、CAGR3 40%+，增速可能因高基数或投入期骤降。
- **三道关**：**关③（PEG/增速兑现）最严**——分位低但必须确认"下一份财报增速仍在"，否则从 A 滑向 C/D。
- **操作**：轻仓/跟踪，看增速兑现度，**不单纯因分位低加仓**。
- **案例**：快手-W（1024）、哔哩哔哩-W（9616）——减亏/高增但尚未稳定盈利。

#### C 型 · 强周期（Cyclical）
- **含义**：净利随行业景气/爆款周期大幅波动，PE 在景气高点看似极低、低点看似极高——**是 PE 估值最容易失效的类型**。
- **特征**：**CV > 0.5**（核心判据）、单季净利跳变数倍、净利同比忽正忽负。
- **三道关**：**禁用单一 PE**；关①改为判断"周期位置（峰/谷）+ 拐点信号（净利单季是否重新转正）"；估值改用 **PB-ROE + 市销率 PS + 周期位置**综合。
- **操作**：**等"周期拐点 + 净利单季转正 + 站上 MA20"三者齐备再加码**，绝不因 PE 低左侧重仓。
- **案例**：小米集团（HK01810）——净利 2025 年跳升、2026 单季 -57.5%、CV 0.62 → **C 型强周期**，PE 低是周期峰值的假象。

#### D 型 · 困境负增长（Distressed）
- **含义**：盈利趋势明确向下，低 PE 多由"盈利崩塌、分母变小"造成，是典型的**价值陷阱**。
- **特征**：`gr1y < 0` 且 `slope < 0`（连续下滑）、PEG 失效（为负）、常伴随 ROE 下滑、技术面空头排列。
- **三道关**：**关①一票否决——增速转正前不加仓**；PE 分位再低也不构成买入理由。
- **操作**：**等"净利同比重新转正 + 连续两季增长 + 股价站上 MA20"确认拐点后再考虑**，此前仅观察。
- **案例**：蔚来-SW（9866）、部分处于转型阵痛期的标的。

### 3.4 分型判据速记口诀

> **"先看方向定 D/C，再看速度分 A/B；CV 过半是周期，增速转正才出困。"**
> - 方向向下（gr1y<0 + slope<0）→ D
> - CV>0.5 → C
> - 增速极快（>50%）→ B
> - 其余 → A

### 3.5 分型的输出契约（每个分析必答）

输出中须明确给出：
1. **判定为 X 型的依据**（列出 gr1y / CAGR3 / ROE / CV / slope 的具体数值）；
2. **命中优先级的哪一条**；
3. **该型对应的三道关松紧**（如"C 型 → 关①看周期位、禁用PE"）；
4. **该型的操作倾向**（核心仓 / 轻仓 / 等拐点 / 不加仓）。

## 4. 三道关（防价值陷阱）

- **关① 绝对值 & 趋势**：分位低+净利正增长 → 非陷阱；分位低+净利崩塌 → 价值陷阱（如"过去是高增长明星、现在盈利崩了"）。
- **关② 口径一致性**：归母 vs 归属（扣非）差异>15% → 自动切换并警示（含投资收益/资产处置的一次性损益会系统性压低 PE）。
- **关③ 增长 vs 估值（PEG）**：PEG=PE÷净利增速；<0.8 偏低估、0.8-1.2 合理、>1.5 偏贵；净利负增长则 PEG 失效，归入 D 型。

## 5. 回测防误用四过滤（本轮新增，修正"低分位≠底部"）

| 过滤 | 检查项 | 触发后果 |
|---|---|---|
| C1 预期增速换挡 | 未来4季一致预期净利增速 vs 过去4季(TTM) | 预期下修 → 分位结论降档 |
| C2 Capex-FCF | 资本开支同比、自由现金流趋势 | AI/周期高投入 → **PE 低需打折** |
| C3 回购力度 | 当期回购金额同比 | 回购缩水 → 估值托底下限减弱 |
| C4 指数β+技术面 | 恒生科技趋势、南向/外资流向、MA20/60/120 站姿 | 下行周期+三线压制 → 低分位仍暴露 |

## 6. 特殊类型处理

- **周期股（C 型）**：PE 随景气剧烈波动，禁用单一 PE 做估值结论；改用 **PB-ROE、市销率 PS、分位 + 周期位置**综合判断；等"周期拐点 + 净利单季转正"再加码。
- **亏损/微利股**：PE 无意义；直接用 **PB-ROE、市销率、分位 + 周期位置**；关注毛利、经营现金流、烧钱速率。
- **港股折价**：需叠加**估值折价（折让于 A 股/美股同类）+ 回购力度 + 南向资金偏好**判断。

## 7. 已知局限（务必在输出中说明）
1. 单窗口分位"低"不代表底部；分位只是概率工具，不是买卖点。
2. 窗口不同分位含义不同，跨平台/跨窗口数值不可混用。
3. 净利口径（归母/归属/Non-GAAP）差异可达数倍，务必统一口径。
4. 历史数据不足时（月K<5年）长窗口分位不可算，须如实标注，不编造。
5. 财务数据有延迟，以交易所官方为准。
