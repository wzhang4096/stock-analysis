# 输出契约（output-contracts）

> 所有基于本 Skill 的估值报告，**必须**遵循本章节的七段式结构与字段约定，以保证可复现、可横向对比。

---

## 一、强制章节（按顺序）

### §1 当前核心数据
以表格呈现，至少包含：
`股价 / 涨跌幅 / 总市值 / 接口 PE / PB / 股息率 / 52周区间与当前位置 / 年初至今(YTD) / 总股本`。
数据取自 `westock quote`，注明数据日期。

### §2 口径说明
- 分子：市值 = 股价 × 总股本（单位：亿）；
- 分母：归母净利滚动 4 季；**若扣非口径优先，说明一次性损益占比**；
- 自建 PE-TTM vs 接口 PE：差异 > 10% 必须解释；
- 币种、单位统一说明。

### §3 PE-TTM 历史分位表
四行固定结构：

| 窗口 | PE 区间 | 当前分位 | 估值状态 |
|---|---|---|---|
| 1年 | min ~ max | xx% | ... |
| 3年 | min ~ max | xx% | ... |
| 5年 | min ~ max | xx% | ... |
| 10年/上市以来 | min ~ max | xx% | ... |

- **窗口陷阱提示**：若各窗口分位极差 > 20pct，解释历史极端值稀释效应；
- 分位 = `100 × (序列中小于当前值的元素个数) / 序列长度`。

### §4 三道关诊断（先分型）
**先声明分型**：A（稳定成长）/ B（高速成长）/ C（周期）/ D（困境负增长）。
再按 `methodology.md` 第四节逐关判定，每关给出 ✅ / ⚠️ / ❌。

### §5 基本面交叉验证
固定 5 个维度：
| 维度 | 指标 |
|---|---|
| 估值分位 | §3 结论 |
| 盈利趋势 | 净利增速、营收增速、ROE |
| PB-ROE | PB、年化 ROE、PB/ROE |
| 技术面 | 均线排列（MA20/60/120/250）、RSI、KDJ、MACD |
| 机构态度 | 评级分布、目标价空间、一致预期净利 |

### §6 综合结论 + 操作倾向
映射规则（20/70 双阈值 + 三道关）：
- 三道关全过 → "确定性低估，可布局"；
- D 型未过"盈利拐点"关 → "博弈区 / 需等拐点，轻仓左侧 + 定投，禁重仓"；
- C 型仍用 PE → "方法不适用，改用 PB-ROE"。

### §7 免责声明（模板）
> 以上为基于公开数据接口的客观估值分析，不构成投资建议。数据可能有延迟，以交易所官方为准，投资有风险，决策需谨慎。

## 二、阈值映射（判定速查）

### 估值分位 → 状态
| 分位 | 状态 | 倾向 |
|---|---|---|
| < 20% | 极度低估 | 分批建仓 |
| 20%–50% | 低估/合理偏低 | 可定投 |
| 50%–70% | 合理中枢 | 持有 |
| 70%–90% | 偏高/高估 | 停止买入、减仓 |
| > 90% | 极度高估 | 止盈 |

### 盈利趋势分型 → 关键判据
| 分型 | 关① 增速 | 关② 趋势 | 关③ 质量 |
|---|---|---|---|
| A 稳定成长 | 增速 ≥ 10%，PEG < 1 | TTM<静态=加速 | ROE ≥ 15% |
| B 高速成长 | 增速 ≥ 30% | 高增速容忍低 ROE | 毛利率、经营现金流 |
| C 周期 | **改用 PB / 正常化盈利** | 行业景气位置 | 产能利用率、大宗价格 |
| D 困境 | **增速<0 为一票否决** | 需站上 MA20/MA60 | 等盈利拐点 |

## 三、风格约定
- 数字统一保留 1-2 位小数；金额单位"亿"或"万亿"；
- 关键结论用**加粗**，风险提示用 ⚠️，一票否决用 ❌；
- 涉及"价值陷阱""窗口陷阱""口径差异"必须显式标注；
- 报告末尾可附横向对比表（如与同行业 / 同框架标的对比）。
