# 输出契约（Output Contract）

## 一、必须包含的数据字段
- 股价、总市值（或流通市值）、PE-TTM（重建值 + 接口值 + 差异说明）
- PB、TTM 归母净利、同比增速（TTM 增速 / 单季增速 / 中期增速）
- ROE（年化加权或半年口径）、股息率
- 可选：Non-GAAP 净利、经营现金流净额

## 二、分位表固定列
每个窗口一行，含：窗口名、该窗口 PE 区间 [min, max]、当前 PE 分位值、相对中位数/75分位的高低幅度、估值解读。

## 三、判定映射（固定规则）
| 当前分位 | 判定 | 操作倾向 |
|---|---|---|
| < 20% | 极度低估 | 建仓/定投，越跌越买 |
| 20-50% | 低估 | 可建仓 |
| 50-70% | 合理 | 持有 |
| 70-90% | 偏高/高估 | 分批减仓 |
| > 90% | 极度高估 | 止盈清仓 |

## 四、四段式输出结构（不可省略）
1. **核心数据**（表格）
2. **分位表**（各窗口）
3. **三道关判断**（关1绝对值 / 关2 TTM-vs-静态 / 关3 增速方向 + 双阈值判定）
4. **结论与操作建议**（综合结论 + 分批方案 + 风险提示）

## 五、风险提示必须包含
- 低估值可能"低很久"（港股折价、周期股底部区间）
- 盈利预期下修会抬升 PE
- 分位仅为概率工具，非精确买卖点

## 六、免责声明（固定结尾）
> 以上为基于公开数据的客观估值分析，不构成投资建议。数据可能有延迟，请以交易所官方为准，投资有风险，决策需谨慎。

## 七、风格要求
- 结论先行，表格辅助，避免说教
- 明确区分"重建计算值"与"行情接口值"，差异>15%必须标注
- 不编造数据；缺数据时如实说明并给出可用口径
