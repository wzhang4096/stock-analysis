# 输出契约（output-contracts）

## 一、五段式输出结构

1. **基础估值**：截面数据（价/市值/PE/PB/股息率/52周）+ 多窗口分位表
2. **分型 + 三道关**：分型结论 + 三关判定（仅打印 PASS/WARN/FAIL）
3. **四过滤**：逐项检查结果与对估值的影响
4. **综合判定**：四档结论 + 操作倾向（双阈值20/70 + 加码信号）
5. **结论更新**：与历史时点对比，标注规则修正点

## 二、四档结论定义

| 档位 | 条件 | 操作倾向 |
|---|---|---|
| ① 确定性低估 | 分位<20% + 分型 A + 三道关全过 + C1/C2/C3 无明显扣分 | 可直接布局/核心仓 |
| ② 低估 | 分位 20%-50% + 分型 A/B + 三道关基本过 | 可分批/定投 |
| ③ 合理偏低 | 分位 50%-70%，或 A 型但 C1/C4 有扣 | 观察，等信号 |
| ④ 博弈区 | 分型 C/D，或 C2/C3 重扣分，或三线压制 | 等拐点，不左侧 |

## 三、分型加分项

| 分型 | 加分 | 典型操作 |
|---|---|---|
| A 稳定成长 | +5 | 核心底仓、分位<20% 可分批 |
| B 高速成长 | +3 | 轻仓/跟踪，看增速兑现 |
| C 强周期 | 0 | 禁用单一 PE，等周期拐点+净利转正+站上 MA20 |
| D 困境 | −5 | 关①否决，增速转正前不加仓 |

## 四、六维打分表（多标的排名用）

| 维度 | 权重 | 字段 | 打分要点 |
|---|---|---|---|
| V1 估值分位 | 25 | 各窗口 PE 分位 | <20%→22-25；20-50%→14-21；50-70%→8-14；>70%→2-8 |
| V2 盈利趋势 | 20 | 归母同比、3年复合、环比斜率 | 双位数+ROE稳→18-20；个位数→10-15；负增长→<5 |
| V3 三道关 | 15 | 口径一致、非陷阱、PEG | 全过→13-15；基本过→8-12；有 WARN→<8 |
| V4 Capex-FCF | 15 | 资本开支同比、FCF趋势 | FCF正→13-15；持平→8-12；负→2-7（AI/周期高投入打折）|
| V5 回购+β | 10 | 回购力度、指数β暴露 | 回购强+β中性→8-10；回购弱/配股稀释→2-5 |
| V6 技术面 | 15 | MA20/60/120 站姿、趋势 | 三线全上+上行→13-15；空头排列→3-8 |
| 分型加分 | ± | 见上表 | A+5 / B+3 / C0 / D−5 |

## 五、多市场横向对比输出

| 维度 | 表现 |
|---|---|
| 各市场独立排名 | 港股 / 美股 / A股 分别输出 Top N |
| 跨市场共识股 | "三市场共同标的"提炼（多为分型 A、低 PE、双位数增长、健康 ROE）|
| 高弹性变量 | 跨市场共同的"高增长高弹性"赛道（如 A股 CPO 光模块 / 美股 AI 芯片）|

## 六、字段4 必答（分型部分）

每个分析的分型段须给出：
- 判定依据数值（gr1y / CAGR3 / ROE / CV / slope）
- 命中优先级哪一条
- 该型三道关松紧
- 操作倾向（核心仓 / 轻仓 / 等拐点 / 不加仓）
