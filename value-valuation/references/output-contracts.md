# 输出契约（output-contracts）

## 1. 强制字段
每个分析必须包含：

| # | 字段 | 内容 |
|---|---|---|
| 1 | 截面数据 | 日期、价、市值、PE、PB、股息率、52周区间、年初至今 |
| 2 | 多窗口分位表 | 1年/3年/5年/10年/上市以来 + 窗口陷阱告警 |
| 3 | PE 口径校验 | 归母 vs 归属差异%、是否切换、切换原因 |
| 4 | 盈利分型 | **A/B/C/D + 判定依据（gr1y/CAGR3/ROE/CV/slope 数值）+ 命中优先级哪一条 + 该型三道关松紧 + 操作倾向**（详见 methodology.md §3.5）|
| 5 | 三道关 | 关①②③ 各输出 PASS / WARN / FAIL + 一句话依据 |
| 6 | 四过滤 | C1 预期增速 / C2 Capex-FCF / C3 回购 / C4 指数β+技术面 逐项结果 |
| 7 | 综合档位 | 四档之一：①确定性低估 ②低估 ③合理偏低 ④博弈区 |
| 8 | 操作倾向 | 仓位建议 + 加码信号（量化阈值）|
| 9 | 历史对比 | 与之前时点对比 + 本次规则修正点 |
| 10 | 免责声明 | 必含 |

## 2. 阈值映射表（输出时附于正文）
| PE 分位 | 估值状态 | 操作倾向 |
|---|---|---|
| <20% | 低估 | 可建仓/定投，越跌越买 |
| 20%-50% | 合理偏低 | 可分批建仓 |
| 50%-70% | 合理中枢 | 持有不动 |
| 70%-90% | 偏高 | 停止买入、分批减仓 |
| >90% | 极度高估 | 止盈清仓 |

## 3. 四档结论定义
| 档位 | 定义 | 仓位 |
|---|---|---|
| ①确定性低估 | 估值低 + A型成长 + 三道关全过 + 四过滤无硬伤 | 核心底仓 |
| ②低估 | 估值低 + 分型健康 + 三道关基本全过 | 分批建仓 |
| ③合理偏低 | 估值低但缺一项（趋势未修复/增速换挡/回购缩量）| 观察+左侧轻仓 |
| ④博弈区 | 低PE源于周期/困境/高投入，或四过滤触发硬伤 | 等拐点再加码 |

## 4. 推荐排序打分表（多标的分析用）
| 维度 | 权重 | 高分特征 |
|---|---|---|
| V1 估值分位 | 25% | 分位低 |
| V2 盈利趋势 | 20% | 净利正增长+ROE高+环比斜率正；**A/B 型加分，C 型中性，D 型扣分** |
| V2b 分型 | +5%(加分) | **A 型 +5%、B 型 +3%、C 型 0%、D 型 -5%**（盈利趋势分型，见 methodology.md §3）|
| V3 三道关 | 15% | 三关全过 |
| V4 Capex-FCF | 15% | 自由现金流为正、Capex可控 |
| V5 回购+β | 10% | 回购力度强、指数趋势向上 |
| V6 技术面 | 15% | 站上MA20/MA60、放量企稳 |

降序输出 Top N + 分档（第一梯队强推荐 / 第二梯队谨慎 / 第三梯队观察 / 第四梯队暂不纳入）。

## 5. 脚本输出格式（pe_percentile.py）
```
【A】基础估值: 价/市值/PE/PB/股息率 + 各窗口分位表(含极差与陷阱告警)
【B】分型+三道关: 分型 + 关①②③ PASS/WARN/FAIL
【C】回测防误用四过滤: C1-C4 逐项结果 + 对估值的影响
【D】综合判定: 四档 + 操作倾向 + 加码信号
```
