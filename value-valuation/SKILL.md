# value-valuation

## 何时使用
当用户希望对某一标的（个股 / 指数）给出**可复现的估值结论**（分位 + 贵贱判定 + 操作倾向），尤其涉及"历史分位""价值投资""低估 / 高估""安全边际"等诉求时触发。

## 执行流程（严格按顺序）

### Step 1 — 取数
通过 westock 数据接口取：
- `westock quote <code>` → 股价、市值、总股本、接口 PE/PB、股息率、52周高低、YTD
- `westock finance <code> --type income` → 季度归母净利（至少近 3 年，用于滚动 4 季 TTM）
- `westock technical <code>` → MA5/10/20/60/120/250、RSI、KDJ、MACD（技术面趋势判定）
- `westock rating <code>` + `westock consensus <code>` → 机构评级、目标价、一致预期净利（D 型 / 博弈区用）

### Step 2 — 重建 PE-TTM 序列
- 单位统一：市值（港元）= 股价 × 总股本；净利换算为"亿"；`PE = 市值 ÷ 滚动4季归母净利`
- 生成月度 / 季度 PE-TTM 序列，计算 **1y / 3y / 5y / 10y（上市以来）** 四档分位
- **口径校验**：若自建 PE 与 `quote` 接口 PE 差异 > 10%，排查"归母 vs 扣非 / 股本取值时点"并在输出中明示

### Step 3 — 口径判定（关键）
- 计算"一次性损益占比" = (归母净利 − 扣非净利) ÷ 归母净利
- 占比 > 15% → **分母切换为扣非净利**，重算分位

### Step 4 — 盈利趋势分型（**新增**）
根据净利增速、ROE、盈利波动判定为 **A（稳定成长）/ B（高速成长）/ C（周期）/ D（困境负增长）**，详见 `references/methodology.md` 第四节。

### Step 5 — 三道关差异化校验
按分型套用规则：
- **A / B 型**：关①增速(PEG) → 关②TTM vs 静态 → 关③ROE/现金流
- **C 型（周期）**：**禁用单纯 PE 分位**，改用跨周期正常化盈利 + PB-ROE + 景气位置
- **D 型（困境/负增长）**：关①增速为一票否决（负增长则必须等盈利拐点）；关②要求站上 MA20/MA60；关③看机构预期差，仅轻仓左侧 + 定投

### Step 6 — 交叉验证
PE 分位 + PB/ROE + 技术面 + 机构评级/一致预期，四维度联合。

### Step 7 — 输出
严格按 `references/output-contracts.md` 的七段式结构成文，含免责声明。
- 跨窗口分位差异 > 20pct 时，必须解释"窗口陷阱"；
- D 型未过"盈利拐点"关时，结论必须标注"博弈区 / 需等拐点"，不得给出"确定性低估"。

## 注意事项
- 本 Skill 给出的是**客观估值分析，不构成投资建议**；数据可能有延迟，以交易所官方为准。
- 行情接口单位为港元（港股），跨市场比较需统一币种。
- 分位是概率工具，低分位 ≠ 马上涨；务必结合盈利趋势与技术面。
