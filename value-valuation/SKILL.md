# 估值分位诊断 Skill

## 一、触发条件

满足任一即触发：

- 用户要求"估值/分位/PE/低估/高估/是否值得买/买入顺序/性价比"类分析，并提及个股、指数、ETF
- 用户要求用"这个 Skill"或指定本 Skill 分析某标的
- 用户要求"回测/截面/测试"某历史日期的估值

## 二、执行流程（7 步，严格按序）

### 步骤 1：取数（优先用 westock 接口）
```bash
westock quote   <code>                 # 实时行情：价格/市值/PE/PB/股息率/52周
westock kline   <code> --period month --limit 300   # 月K（重建PE-TTM序列）
westock finance <code> --type income --limit 20      # 季度财务：归母/扣非净利、ROE、营收
westock quote   <code> --raw > q.json
westock kline   <code> --period month --limit 300 --raw > k.json
westock finance <code> --type income --limit 20 --raw > f.json
```

### 步骤 2：重建 PE-TTM 序列（若传 kline+finance）
- `PE_ttm(m) = MKT(m) / 归母滚动4季净利`
- 月K日期自动对齐到月末（月末季结，避免"月初日K价格 × 单季净利"失真）
- 总股本从 `quote` 取（更新公告可能调整）

### 步骤 3：多窗口分位（1年/3年/5年/10年/上市以来）
- 统计各窗口 PE 的 min/max，算目标 PE 分位
- **窗口陷阱检测**：极差 > 20pct → 触发告警，说明长窗口被极端值稀释，按 Skill 阈值（20/70）判定以**短期窗口为准**，长窗口仅作参考

### 步骤 4：PE 口径校验
- 算 `PE(归母TTM)` 与 `PE(归属TTM)`（来自接口）：差异 > 15% → **自动切换为归属口径**，提示"归母含一次性收益/投资收益，虚高 PE、低估便宜度"
- 腾讯案例：归母口径 PE 14.6x vs 归属口径 6.2x，差异 +135%，以归母口径（更保守）为准

### 步骤 5：盈利趋势分型（决定三道关如何执行）
> 定义、判定公式、优先级、各型三道关松紧、案例见 `references/methodology.md §3`（核心：CV>0.5→C型；gr1y<0且slope<0→D型；gr1y>50%→B型；其余→A型）。

| 分型 | 中文 | 判定标准 | 分位参考 | 三道关 |
|---|---|---|---|---|
| **A 稳定成长** | 主业成熟、盈利可预测 | 净利同比>0 且 ROE 20%+/3年复合高 | 偏低即低估 | 宽松，常全过 |
| **B 高速成长** | 爆发期、增速快但不稳 | 净利同比 50%+、CAGR3 40%+ | 偏低但需看持续性 | **关③最严**，看增速兑现 |
| **C 强周期** | 净利随景气大幅波动 | **净利波动 CV>0.5**，单季大幅跳变 | **禁用单一 PE** | 关①看周期位+拐点，用 PB/PS |
| **D 困境负增长** | 盈利趋势明确向下 | 净利同比<0 且 slope<0 | 即便低分位也慎用 | **关①一票否决**（增速转正前不加仓）|

**核心公式**：`CV = 近12季净利标准差 / 均值`（>0.5 → C 型）；`slope = 近4季净利线性回归斜率`。
**优先级（互斥，自上而下命中即停）**：① `gr1y<0 且 slope<0` → D；② `CV>0.5` → C；③ `gr1y>50% 或 CAGR3>40%` → B；④ 其余 → A。
**输出契约**：每个分析须给出「判定依据数值 + 命中优先级哪条 + 该型三道关松紧 + 操作倾向」（详见 `output-contracts.md` 字段4）。

### 步骤 6：三道关（防价值陷阱，每一步仅打印判定）
- **关① 绝对值 & 趋势**：分位低 + 净利正增长 → 非陷阱；分位低 + 净利崩塌 → **价值陷阱**
- **关② 口径一致性**：归母 vs 归属差异 >15% → 切换并警示
- **关③ 增长 vs 估值（PEG）**：PEG = PE ÷ 净利增速；PEG<0.8 偏低估，>1.5 偏贵；净利负增长则 PEG 失效

### 步骤 7：回测防误用四过滤（本轮新增，修正"低分位≠底部"）
| 过滤 | 检查项 | 触发后果 |
|---|---|---|
| **C1 预期增速换挡** | 未来4季一致预期净利增速 vs 过去4季（TTM） | 预期下修 → 分位结论降档 |
| **C2 Capex-FCF** | 资本开支同比、自由现金流趋势 | AI/周期高投入 → **PE 低需打折** |
| **C3 回购力度** | 当期回购金额同比 | 回购缩水 → 估值托底下限减弱 |
| **C4 指数β+技术面** | 恒生科技趋势、南向/外资流向、MA20/60/120 | 下行周期+三线压制 → 低分位仍暴露 |

最终结论 = 估值分位(A) × 盈利分型(B) × 三道关(C) × 四过滤(C) × 技术面 → 四档：
**① 确定性低估（可直接布局）/ ② 低估（可分批）/ ③ 合理偏低（观察）/ ④ 博弈区（等拐点）**

## 三、输出契约（四段式）

1. **基础估值**：截面数据（价/市值/PE/PB/股息率/52周）+ 多窗口分位表
2. **分型 + 三道关**：分型结论 + 三关判定（仅打印 PASS/WARN/FAIL）
3. **四过滤**：逐项检查结果与对估值的影响
4. **综合判定**：四档结论 + 操作倾向（双阈值20/70 + 加码信号）
5. **结论更新**：与历史时点对比，标注规则修正点

## 四、脚本约定

`scripts/pe_percentile.py`：`analyze(price, market_cap, pe_ttm=None, kline=None, finance=None, name="")` 或 `--batch <json>` 批量。
输出含：多窗口分位、窗口陷阱检测、口径校验告警、分型判定、三道关、四过滤、综合档位、操作倾向。
